Rappel 2 — Suite croissante, suite décroissante

La suite (un​) est croissante si, pour tout n∈N, un+1​≥un​ ; décroissante si, pour tout n∈N, un+1​≤un​. Elle est croissante à partir du rang p si un+1​≥un​ pour tout entier n≥p.

Rappel 3 — Trois méthodes de 1re

  • Différence : si, pour tout n∈N, un+1​−un​≥0, alors (un​) est croissante ; si un+1​−un​≤0, elle est décroissante.
  • Quotient, pour une suite à termes strictement positifs : si, pour tout n∈N, un​un+1​​≥1, alors (un​) est croissante ; si un​un+1​​≤1, elle est décroissante. Utile quand un​ contient des puissances qn.
  • Fonction associée, pour une suite un​=f(n) : si f est croissante sur [0;+∞[, alors (un​) est croissante ; si f est décroissante, elle est décroissante.

Pour chaque exercice, il y a souvent une méthode nettement plus simple que les autres : c'est l'expérience qui permet de la choisir. En cas d'impasse, ne pas hésiter à en essayer une autre.

Exercice 18 — Suites récurrentes : la méthode de la différence

Étudier le sens de variation de chacune des suites (un​), (vn​), (wn​) ci-dessous.

  1. a)
    (un​) définie par u0​=0 et, pour tout n∈N, un+1​=un​+n2−5n+6 (on pourra factoriser n2−5n+6).
  2. b)
    (vn​) définie par v0​=1 et, pour tout n∈N, vn+1​=vn​−vn2​+12​.
  3. c)
    (wn​) définie par w0​=2 et, pour tout n∈N, wn+1​=wn2​−wn​+1.
Corrigé

a)

un+1​−un​
=n2−5n+6
la relation donne directement la différence
un+1​−un​
=(n−2)(n−3)
on vérifie : n2−3n−2n+6
Pour un entier n≤2, les deux facteurs sont négatifs ou nuls ; pour un entier n≥3, ils sont positifs. Il n'y a pas d'entier strictement entre 2 et 3 : le produit est toujours positif ou nul, donc (un​) est croissante.
le seul endroit où le produit est négatif, ]2;3[, ne contient pas d'entier

b)

vn+1​−vn​
=−vn2​+12​
On a vn2​+1>0, donc vn+1​−vn​<0 : (vn​) est décroissante.
un carré plus 1 est strictement positif

c)

wn+1​−wn​
=wn2​−wn​+1−wn​
wn+1​−wn​
=wn2​−2wn​+1
wn+1​−wn​
=(wn​−1)2
identité remarquable
Un carré est positif, donc wn+1​−wn​≥0 : (wn​) est croissante.

→ Pour une suite un+1​=f(un​), la différence un+1​−un​ s'écrit avec un​ : on cherche son signe sans connaître un​ (carré, quotient de nombres positifs).
