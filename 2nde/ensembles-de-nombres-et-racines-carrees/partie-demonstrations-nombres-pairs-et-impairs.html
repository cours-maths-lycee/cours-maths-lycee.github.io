Propriété 4 — Carré d'un entier impair

Le carré d'un entier impair est impair.

Démonstration. Soit a un entier impair : a=2k+1, avec k entier.

a2
=(2k+1)2
on remplace a
a2
=4k2+4k+1
identité remarquable (a+b)2 (chapitre 4)
a2
=2(2k2+2k)+1
on factorise 4k2+4k par 2
a2
=2v+1
on pose v=2k2+2k
v est un entier.
forme 2k+1
Conclusion : le carré d'un entier impair est impair.

Conséquence, utile à la partie VII

Si a2 est pair, alors a est pair : si a était impair, a2 serait impair (propriété 4).

Méthode 6 — Démontrer en séparant les cas pair et impair

Exemples corrigés

On ne sait pas si l'entier n est pair ou impair : on traite les deux cas (disjonction des cas). Tester pour n=2 et n=3, puis démontrer que, pour tout entier n, n2+n est pair.

Correction

Résolution

Test : pour n=2 : 4+2=6 ; pour n=3 : 9+3=12. Les deux sont pairs.
un entier pair, un entier impair : les deux cas
1er cas : n est pair, n=2k avec k entier.
n2+n
=(2k)2+2k
on remplace n
n2+n
=4k2+2k
n2+n
=2(2k2+k)
on factorise par 2
n2+n
=2v
on pose v=2k2+k, entier : pair
2e cas : n est impair, n=2k+1 avec k entier.
n2+n
=(2k+1)2+2k+1
on remplace n
n2+n
=4k2+4k+1+2k+1
identité remarquable
n2+n
=4k2+6k+2
on réduit
n2+n
=2(2k2+3k+1)
on factorise par 2
n2+n
=2w
on pose w=2k2+3k+1, entier : pair
Conclusion : dans les deux cas, n2+n est pair : il est pair pour tout entier n.
on conclut sur tous les entiers

Exercice 17 — Carré d'un entier pair

  1. a)
    Calculer 42, 62 et 102. Que remarque-t-on ?
  2. b)
    Démontrer que le carré d'un entier pair est pair.
  3. c)
    Avec la propriété 4 du cours, que peut-on dire de la parité d'un entier et de celle de son carré ?
Corrigé

a)

42=16 ; 62=36 ; 102=100 : les carrés de ces entiers pairs sont pairs.

b)

Soit a=2k un entier pair.
a2
=(2k)2
a2
=4k2
(2k)2=22×k2
a2
=2(2k2)
a2
=2v
on pose v=2k2, entier
Conclusion : le carré d'un entier pair est pair.

c)

Un entier pair a un carré pair (question b), un entier impair a un carré impair (propriété 4) : un entier et son carré ont la même parité.

Exercice 19 — Carré d'un impair moins un

a est un entier impair : a=2k+1, avec k entier.

  1. a)
    Calculer a2−1 pour a=7, puis pour a=11. Ces nombres sont-ils des multiples de 8 ?
  2. b)
    Démontrer que a2−1=4(k2+k).
  3. c)
    À l'aide de l'exemple corrigé de la méthode 6, démontrer que a2−1 est un multiple de 8.
Corrigé

a)

b)

Exercice 20 — Vrai ou faux sur la parité

Tester chaque affirmation pour n=1, n=2 et n=3, puis dire si elle est vraie ou fausse, et justifier.

  1. a)
    Pour tout entier n, n2+1 est impair.
  2. b)
    Pour tout entier n, 4n+7 est impair.
  3. c)
    Pour tout entier n, n2+2n est pair.
  4. d)
    Pour tout entier n, n(n+1)(n+2) est pair.
Corrigé

a)

Test : pour n=1 ; 2 ; 3, n2+1 vaut 2 ; 5 ; 10.
Pour n=1, n2+1=2 est pair : contre-exemple.
Conclusion : faux.
n2+1 est impair seulement quand n est pair

b)

Test : 4n+7 vaut 11 ; 15 ; 19.
4n+7
=4n+6+1
4n+7
=2(2n+3)+1
4n+7
=2v+1
on pose v=2n+3, entier
Conclusion : vrai.

c)

Test : n2+2n vaut 3 ; 8 ; 15.
Pour n=1, n2+2n=3 est impair : contre-exemple.
Conclusion : faux.

d)

Test : n(n+1)(n+2) vaut 6 ; 24 ; 60.
n(n+1)=n2+n est pair (exemple de la méthode 6) : n(n+1)=2v, avec v entier.
n(n+1)(n+2)
=2v(n+2)
n(n+1)(n+2)
=2w
on pose w=v(n+2), entier
Conclusion : vrai.
un produit qui contient un facteur pair est pair
