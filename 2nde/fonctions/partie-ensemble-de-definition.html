Deux calculs impossibles

Certains nombres n'ont pas d'image, parce que le calcul est impossible : ce sont des valeurs interdites.

  • Avec f(x)=x1​, f(0)=1÷0 n'existe pas : on ne divise pas par zéro. Le nombre 0 est une valeur interdite.
  • Avec g(x)=x​, g(−4)=−4​ n'existe pas : un nombre négatif n'a pas de racine carrée. Tous les nombres strictement négatifs sont interdits.

Définition 9 — Ensemble de définition

L'ensemble de définition d'une fonction f, noté Df​, est l'ensemble des nombres qui ont une image par f. On note f:Df​⟶R, x⟼f(x).

Exemples : Df​=]−∞;0[∪]0;+∞[ pour f(x)=x1​ ; Dg​=[0;+∞[ pour g(x)=x​.

Propriété 2 — À retenir

  • Une fonction affine f(x)=ax+b est définie sur R, comme toute expression sans quotient ni racine carrée (par exemple x2+5x−3).
  • Un dénominateur ne doit pas être nul : les nombres qui l'annulent sont des valeurs interdites.
  • Sous une racine carrée, le nombre doit être positif ou nul.

Méthode 9 — Déterminer un ensemble de définition

Sans quotient ni racine : Df​=R. Avec un quotient : on retire de R la valeur interdite. Avec une racine : on résout «  nombre sous la racine ⩾0 » comme une équation (on ajoute ou on retranche un même nombre, on divise par un même nombre positif).

Exercice 18 — Un nombre sans image

Pour chaque fonction ci-dessous, un des nombres −5 ; 2 ; 0 ; 9 n'a pas d'image. Lequel ?

f1​(x)=x1​f2​(x)=x−2x+5​f3​(x)=x​
Corrigé
Pour chaque fonction, on cherche le calcul impossible : une division par zéro, ou la racine carrée d'un nombre négatif.
propriété 2 du cours
f1​ : f1​(0)=01​ n'existe pas, car on ne divise pas par zéro. Le nombre sans image est 0.
les autres en ont une : f1​(2)=21​, f1​(9)=91​…
f2​ : le dénominateur x−2 vaut 0 pour x=2 ; f2​(2)=07​ n'existe pas. Le nombre sans image est 2.
f2​(−5)=−70​=0 existe : un numérateur nul ne gêne pas
f3​ : −5​ n'existe pas, car un nombre négatif n'a pas de racine carrée. Le nombre sans image est −5.
0​=0 et 9​=3 existent

→ Piège pour f2​ : −5 annule le numérateur, pas le dénominateur. Seul un dénominateur nul rend le calcul impossible.
