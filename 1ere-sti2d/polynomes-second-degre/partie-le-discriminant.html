En marge du programme : le discriminant n'y figure plus, mais il donne une méthode simple et générale pour trouver les racines.

Définition 3 — Discriminant

Le discriminant du trinôme ax2+bx+c est le nombre

Δ=b2−4ac​

(lire « delta »).

Propriété 2 — Nombre de racines

Le signe de Δ donne le nombre de racines du trinôme ax2+bx+c :

  • si Δ>0 : deux racines ;
  • si Δ=0 : une seule racine ;
  • si Δ<0 : aucune racine réelle.

Les formules qui donnent ces racines viennent en partie IV.

Méthode 3 — Calculer un discriminant, compter les racines

Exercice 9 — Calculer un discriminant

Calculer Δ et donner son signe.

  1. A =
    x2−2x−15
  2. B =
    x2+2x−15
  3. C =
    x2+2x+15
  4. D =
    −x2+2x−15
  5. E =
    4x2−12x+9
  6. F =
    25x2−10x+1
  7. G =
    −2x2+5x−3
  8. H =
    −3x2+4x−2
  9. I =
    −2x2+7x−3
Corrigé
On lit a, b et c avec leur signe, puis on écrit Δ=b2−4ac en mettant les nombres négatifs entre parenthèses.
méthode 3 du cours
Δf​
=(−2)2−4×1×(−15)
a=1, b=−2, c=−15
Δf​
=4+60=64
Δf​>0
Δg​
=22−4×1×(−15)
a=1, b=2, c=−15
Δg​
=4+60=64
Δg​>0
Δh​
=22−4×1×15
a=1, b=2, c=15
Δh​
=4−60=−56
Δh​<0
Δk​
=22−4×(−1)×(−15)
a=−1, b=2, c=−15
Δk​
=4−60=−56
−4×(−1)×(−15)=−60 : Δk​<0
Δl​
=(−12)2−4×4×9
a=4, b=−12, c=9
Δl​
=144−144=0
Δm​
=(−10)2−4×25×1
a=25, b=−10, c=1
Δm​
=100−100=0
Δn​
=52−4×(−2)×(−3)
a=−2, b=5, c=−3
Δn​
=25−24=1
Δn​>0
Δp​
=42−4×(−3)×(−2)
a=−3, b=4, c=−2
Δp​
=16−24=−8
Δp​<0
Δq​
=72−4×(−2)×(−3)
a=−2, b=7, c=−3
Δq​
=49−24=25
Δq​>0

→ b2 est toujours positif : (−2)2=4. Le signe de −4ac dépend des signes de a et de c : s'ils sont de même signe, −4ac est négatif (h, k, l, m, n, p, q).

→ Erreur fréquente : écrire −22 au lieu de (−2)2 ; la calculatrice donne alors −4.

Exercice 10 — Combien de racines ?

Calculer Δ, puis dire combien le polynôme a de racines.

  1. A =
    x2+5x+4
  2. B =
    x2+4x+5
  3. C =
    x2−8x+7
  4. D =
    9x2+6x+1
  5. E =
    2x2+5x+3
  6. F =
    −3x2−x−2
Corrigé
Le signe de Δ donne le nombre de racines : deux si Δ>0, une seule si Δ=0, aucune si Δ<0.
propriété 2 du cours
Δf​
=52−4×1×4
a=1, b=5, c=4
Δf​
=25−16=9
Δf​>0 : deux racines
Δg​
=42−4×1×5
a=1, b=4, c=5
Δg​
=16−20=−4
Δg​<0 : aucune racine
Δh​
=(−8)2−4×1×7
a=1, b=−8, c=7
Δh​
=64−28=36
Δh​>0 : deux racines
Δk​
=62−4×9×1
a=9, b=6, c=1
Δk​
=36−36=0
Δk​=0 : une seule racine
Δl​
=52−4×2×3
a=2, b=5, c=3
Δl​
=25−24=1
Δl​>0 : deux racines
Δm​
=(−1)2−4×(−3)×(−2)
a=−3, b=−1, c=−2
Δm​
=1−24=−23
Δm​<0 : aucune racine

→ Pour l, Δl​=1 est petit mais positif : il y a bien deux racines. Seul le signe de Δ compte.

Exercice 11 — Quand b ou c est nul

Même consigne. Attention aux termes absents et aux signes.

  1. A =
    x2−25
  2. B =
    −3x2+12
  3. C =
    2x2−7x
  4. D =
    −x2+6x
  5. E =
    −2x2−5
  6. F =
    4x2+1
Corrigé
Un terme absent a un coefficient nul : si b=0, Δ=−4ac ; si c=0, Δ=b2.
méthode 3 du cours
Δf​
=02−4×1×(−25)
a=1, b=0, c=−25
Δf​
=100
Δf​>0 : deux racines
Δg​
=02−4×(−3)×12
a=−3, b=0, c=12
Δg​
=144
Δg​>0 : deux racines
Δh​
=(−7)2−4×2×0
a=2, b=−7, c=0
Δh​
=49
Δh​>0 : deux racines
Δk​
=62−4×(−1)×0
a=−1, b=6, c=0
Δk​
=36
Δk​>0 : deux racines
Δl​
=02−4×(−2)×(−5)
a=−2, b=0, c=−5
Δl​
=−40
Δl​<0 : aucune racine
Δm​
=02−4×4×1
a=4, b=0, c=1
Δm​
=−16
Δm​<0 : aucune racine

→ Quand c=0 (h et k), Δ=b2 est toujours positif (ou nul) : il y a toujours la racine 0, puisqu'on peut factoriser par x.

→ Erreur fréquente pour g : prendre b=12. Le nombre seul est c ; il n'y a pas de terme en x, donc b=0.
