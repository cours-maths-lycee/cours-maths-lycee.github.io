Définition 8 — Échantillon d'une loi de Bernoulli

Un échantillon de taille n d'une loi de Bernoulli de paramètre p est la liste des n résultats (1 ou 0) de n épreuves identiques et indépendantes (partie V). La fréquence observée des 1 dans l'échantillon est

f=nnombre de 1​.

En Python

from random import random

def frequence(n, p):
    nb = 0
    for i in range(n):
        if random() < p:
            nb = nb + 1
    return nb / n

for j in range(5):
    print(frequence(100, 0.2))

random() donne un nombre au hasard entre 0 et 1 ; le test random() < p est vrai avec la probabilité p (seconde) : c'est une épreuve de Bernoulli.

frequence(n, p) simule un échantillon de taille n : nb compte les succès, et la fonction renvoie la fréquence observée des 1.

La boucle finale simule 5 échantillons de taille 100 et affiche leurs 5 fréquences. Avec N à la place de 5, on obtient N fréquences, qu'on représente par un nuage de points ou un histogramme (partie VII).

Exercice 23 — Lire un programme

Dans une imprimerie, 5% des livres présentent un défaut d'impression. On choisit un livre au hasard ; on note D l'événement «  le livre présente un défaut ».

from random import random

def livre():
    x = random()
    if x < 0.05:
        defaut = 1
    else:
        defaut = 0
    return defaut
  1. 1)
    Donner P(D).
  2. 2)
    Expliquer ce que renvoie la fonction livre(), et avec quelle probabilité elle renvoie 1.
  3. 3)
    Compléter la fonction frequence(n), qui renvoie la fréquence des livres avec un défaut dans un échantillon de n livres.
  4. 4)
    frequence(10000) a renvoyé 0.0493. Ce résultat est-il étonnant ? Expliquer.
def frequence(n):
    nb = .....
    for i in range(.....):
        nb = nb + .....
    return .....
Corrigé

1)

5% des livres ont un défaut : P(D)=0,05.
un pourcentage écrit en décimal

2)

livre() renvoie 1 si le livre simulé a un défaut, 0 sinon ; elle renvoie 1 quand x < 0.05, donc avec la probabilité 0,05.
elle simule la loi de Bernoulli de paramètre 0,05

3)

nb = 0, for i in range(n):, nb = nb + livre(), return nb / n.
on part de 0, on ajoute 1 à chaque livre avec un défaut, sur n livres, puis on divise par n
def frequence(n):
    nb = 0
    for i in range(n):
        nb = nb + livre()
    return nb / n

4)

Ce n'est pas étonnant : sur un grand échantillon (10000 livres), la fréquence observée 0,0493 est très proche de p=0,05.
plus l'échantillon est grand, moins la fréquence fluctue (partie VII)

Exercice 25 — La moyenne des fréquences

La fonction frequence(n, p) du cours renvoie la fréquence des 1 dans un échantillon de taille n d'une loi de Bernoulli de paramètre p. Le programme ci-dessous doit afficher la moyenne des fréquences de 500 échantillons de taille 100 : s additionne les fréquences.

s = .....
for j in range(500):
    s = s + .....
print(s / 500)
  1. 1)
    Compléter le programme, avec p=0,3.
  2. 2)
    Le programme a affiché 0.2997. Interpréter ce résultat.
  3. 3)
    Une variable aléatoire X suit la loi de Bernoulli de paramètre 0,3. Donner E(X), puis comparer avec le résultat de la question 2.
Corrigé

1)

s = 0 puis s = s + frequence(100, 0.3).
s part de 0 et additionne les 500 fréquences ; on divise ensuite par 500

2)

La moyenne des fréquences de 500 échantillons de 100 épreuves vaut 0,2997 : les fréquences fluctuent autour de 0,3, et leur moyenne en est très proche.
certaines fréquences sont au-dessus de 0,3, d'autres en dessous

3)

E(X)=p, soit E(X)=0,3 : la moyenne des fréquences, 0,2997, est très proche de l'espérance.
propriété 3 ; la fréquence d'un échantillon est une moyenne des valeurs 1 et 0
