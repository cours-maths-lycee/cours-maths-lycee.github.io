Définition 8 — Échantillon d'une loi de Bernoulli

Un échantillon de taille n d'une loi de Bernoulli de paramètre p est la liste des n résultats (1 ou 0) de n épreuves identiques et indépendantes (partie V). La fréquence observée des 1 dans l'échantillon est

f=nnombre de 1​.

En Python

from random import random

def bernoulli(p):
    if random() < p:
        return 1
    else:
        return 0

def frequence(n, p):
    nb = 0
    for i in range(n):
        nb = nb + bernoulli(p)
    return nb / n

def simulation(N, n, p):
    L = []
    for j in range(N):
        L.append(frequence(n, p))
    return L

random() donne un nombre au hasard entre 0 et 1 ; le test random() < p est vrai avec la probabilité p (seconde).

bernoulli(p) simule une épreuve : elle renvoie 1 (succès) ou 0 (échec).

frequence(n, p) simule un échantillon de taille n : nb compte les succès, et la fonction renvoie la fréquence observée des 1.

simulation(N, n, p) simule N échantillons et renvoie la liste L de leurs N fréquences (L.append ajoute une valeur à la liste). On les représente ensuite par un nuage de points ou un histogramme (partie VII).
