Définition 5 — Valeur interdite

On ne divise pas par 0 : une valeur qui annule le dénominateur d'un quotient est une valeur interdite. Elle n'est jamais solution ; dans le tableau de signes, on la marque d'une double barre.

Remarque

Un quotient suit la même règle des signes qu'un produit. On ne « fait pas passer » le dénominateur de l'autre côté : son signe est inconnu, on ne saurait pas s'il faut changer le sens.

À faire : exercices 31 à 33

Exercice 31 — Premières inéquations quotient

1) Donner la valeur interdite de x+54−x​, 2−x7−2x​ et 3x−9x+2​.

2) Résoudre dans R :

  1. a)
    x+54−x​>0
  2. b)
    3x−9x+2​⩽0
  3. c)
    2−x7−2x​⩾0
  4. d)
    4−x3x+2​<0
Corrigé

1)

x+5=0 pour x=−5 : la valeur interdite de x+54−x​ est −5.
on cherche où le dénominateur s'annule
2−x=0 pour x=2 : la valeur interdite de 2−x7−2x​ est 2.
3x−9=0 pour x=3 : la valeur interdite de 3x−9x+2​ est 3.
3x=9

2) a)

Valeur interdite : −5.
Numérateur : 4−x=0 pour x=4.
le dénominateur d'abord (définition 5 et méthode 10 du cours)

S=]−5;4[.
on lit les + ; double barre en −5

b)

Valeur interdite : 3.
Numérateur : x+2=0 pour x=−2.

S=[−2;3[.
−2 compris (le quotient s'y annule) ; 3 exclu (interdit)

c)

Valeur interdite : 2.
Numérateur : 7−2x=0 pour x=27​.
−2x=−7
7−2x et 2−x ont un coefficient négatif : + puis −.

S=]−∞;2[∪[27​;+∞[.
2 exclu (interdit) ; 27​ compris

d)

Valeur interdite : 4−x=0 pour x=4.
Numérateur : 3x+2=0 pour x=−32​.

S=]−∞;−32​[∪]4;+∞[.
on lit les − ; bornes exclues

→ Même avec ⩽ ou ⩾, la valeur interdite a toujours un crochet ouvert.

Exercice 32 — Avec une factorisation

Résoudre dans R, après avoir donné les valeurs interdites :

  1. a)
    5−2xx(x−2)​⩽0
  2. b)
    2−xx2−16​>0
  3. c)
    x2−96−3x​⩽0
Corrigé
On factorise le numérateur ou le dénominateur s'il le faut ; les valeurs interdites annulent le dénominateur ; puis une ligne par facteur.
méthode 10 du cours

a)

Valeur interdite : 5−2x=0 pour x=25​.
Numérateur : x(x−2) est nul en 0 et en 2.
valeurs rangées : 0 ; 2 ; 25​

S=[0;2]∪]25​;+∞[.
0 et 2 compris ; 25​ exclu

b)

2−xx2−16​
>0
on recopie
2−x(x−4)(x+4)​
>0
on factorise le numérateur
Valeur interdite : 2.
Numérateur nul en −4 et en 4.
valeurs rangées : −4 ; 2 ; 4

S=]−∞;−4[∪]2;4[.
on lit les +

c)

x2−96−3x​
⩽0
on recopie
(x−3)(x+3)6−3x​
⩽0
on factorise le dénominateur
Valeurs interdites : −3 et 3.
Numérateur : 6−3x=0 pour x=2.
deux valeurs interdites, deux doubles barres

S=]−3;2]∪]3;+∞[.

Exercice 33 — Tout ramener d'un même côté

Rappel. On ne « fait pas passer » le dénominateur : on met tout dans le membre de gauche, puis on réduit au même dénominateur pour comparer un seul quotient à 0.

Résoudre dans R :

  1. a)
    x+33x+1​⩽2
  2. b)
    2−x2−5x​⩾3
  3. c)
    3−2xx+4​<1
Corrigé
On passe tout dans le membre de gauche, on réduit au même dénominateur, puis on dresse le tableau de signes du quotient obtenu.
méthode 10 du cours, exemple b)

a)

Valeur interdite : −3.
x+33x+1​
⩽2
on recopie
x+33x+1​−2
⩽0
tout dans le membre de gauche
x+33x+1−2(x+3)​
⩽0
même dénominateur : 2=x+32(x+3)​
x+3x−5​
⩽0
3x+1−2x−6=x−5

S=]−3;5].
−3 exclu (interdit) ; 5 compris

b)

Valeur interdite : 2.
2−x2−5x​
⩾3
on recopie
2−x2−5x​−3
⩾0
tout dans le membre de gauche
2−x2−5x−3(2−x)​
⩾0
même dénominateur : 3=2−x3(2−x)​
2−x−2x−4​
⩾0
2−5x−6+3x=−2x−4
−2x−4=0 pour x=−2 ; −2x−4 et 2−x ont un coefficient négatif : + puis −.

S=]−∞;−2]∪]2;+∞[.
−2 compris ; 2 exclu

c)

Valeur interdite : 3−2x=0 pour x=23​.
3−2xx+4​
<1
on recopie
3−2xx+4​−1
<0
tout dans le membre de gauche
3−2xx+4−(3−2x)​
<0
même dénominateur : 1=3−2x3−2x​
3−2x3x+1​
<0
le − change les signes de 3−2x
3x+1=0 pour x=−31​.
−31​<23​

S=]−∞;−31​[∪]23​;+∞[.
on lit les − ; bornes exclues
