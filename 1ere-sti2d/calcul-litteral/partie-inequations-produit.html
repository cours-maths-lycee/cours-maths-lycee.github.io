Chapitre 1 — Calcul littéral · coursIX Inéquations produit

← Partie précédenteVIII — Tableaux de signesPartie suivante →X — Inéquations quotient

Pour résoudre une inéquation A(x)×B(x)>0 (ou ⩾0, <0, ⩽0), on ne peut pas isoler x : on dresse le tableau de signes du produit, puis on lit les solutions sur la dernière ligne. Si l'expression n'est pas un produit, on la factorise d'abord.

Méthode 9 — Résoudre une inéquation produit

Exemples corrigés

Résoudre dans R les inéquations suivantes.

  1. a)
    (2x+5)(3−x)⩾0
  2. b)
    x2−25<0
  3. c)
    (x+2)(x−1)(4−x)⩾0
Correction

a)

2x+5=0 pour x=−25​ ;   3−x=0 pour x=3.
valeurs qui annulent les facteurs

S=[−25​;3].
on lit les + et les 0 : inégalité large, bornes comprises

b)

x2−25
<0
on recopie
(x−5)(x+5)
<0
on factorise : a2−b2

S=]−5;5[.
inégalité stricte : bornes exclues

c)

Les facteurs s'annulent en −2, 1 et 4.
trois facteurs : trois lignes, puis celle du produit

S=]−∞;−2]∪[1;4].
les solutions forment deux intervalles, réunis par ∪

À vous de jouer

(x−4)(x+6)<0(3x+1)(5−x)⩾0x2−7x⩽0(x+3)(x−2)(5−x)>0

S=]−6;4[ ; S=[−31​;5] ; x(x−7)⩽0, S=[0;7] ; S=]−∞;−3[∪]2;5[.

S=[−31​;5].
on lit les + et les 0 : bornes comprises

⩽0

Exercice 28 — Deux facteurs

Résoudre dans R, à l'aide d'un tableau de signes :

  1. a)
    x(x−3)⩾0
  2. b)
    (x+2)(x−6)<0
  3. c)
    (5−x)(3x+9)⩾0
  4. d)
    (3x−4)(1−5x)<0
Corrigé
On dresse le tableau de signes du produit, puis on lit les solutions sur la dernière ligne : les + pour >0, les − pour <0, avec les 0 si l'inégalité est large.
méthode 9 du cours

a)

Le facteur x est nul pour x=0 ;   x−3=0 pour x=3.
valeurs qui annulent les facteurs

S=]−∞;0]∪[3;+∞[.
on lit les + et les 0 : bornes comprises

b)

x+2=0 pour x=−2 ;   x−6=0 pour x=6.

S=]−2;6[.
on lit les − ; inégalité stricte : bornes exclues

c)

5−x=0 pour x=5 ;   3x+9=0 pour x=−3.
3x+9 : − puis +.
5−x : a=−1<0, donc + puis −.

S=[−3;5].
on lit les + et les 0

d)

3x−4=0 pour x=34​ ;   1−5x=0 pour x=51​.
51​<34​ : 51​ d'abord
1−5x : a=−5<0, donc + puis −.
3x−4 : − puis +.

S=]−∞;51​[∪]34​;+∞[.
on lit les − ; deux intervalles réunis par ∪

→ Inégalité large (⩽, ⩾) : les valeurs qui annulent sont solutions, crochets fermés. Inégalité stricte : crochets ouverts.

Exercice 29 — Trois facteurs

Résoudre dans R :

  1. a)
    x(x−2)(x+4)⩾0
  2. b)
    (x+3)(2−x)(2x−1)<0
  3. c)
    2x(3x−4)(x+6)⩽0
  4. d)
    x(x2−16)>0
Corrigé
Trois facteurs : trois valeurs en tête du tableau, trois lignes, puis celle du produit.
méthode 9 du cours, exemple c)

a)

Les facteurs x, x−2 et x+4 s'annulent en 0, en 2 et en −4 ; tous sont − puis +.
valeurs rangées : −4 ; 0 ; 2

S=[−4;0]∪[2;+∞[.
on lit les + et les 0

b)

x+3=0 pour x=−3 ;   2−x=0 pour x=2 ;   2x−1=0 pour x=21​.
valeurs rangées : −3 ; 21​ ; 2
x+3 et 2x−1 : − puis +.
2−x : a=−1<0, donc + puis −.

S=]−3;21​[∪]2;+∞[.
on lit les − ; bornes exclues

c)

2x=0 pour x=0 ;   3x−4=0 pour x=34​ ;   x+6=0 pour x=−6.
valeurs rangées : −6 ; 0 ; 34​
Les trois facteurs ont un coefficient positif : − puis +.

S=]−∞;−6]∪[0;34​].
on lit les − et les 0

d)

x(x2−16)
>0
on recopie
x(x−4)(x+4)
>0
x2−16=(x−4)(x+4)
Les facteurs s'annulent en −4, en 0 et en 4 ; tous sont − puis +.

S=]−4;0[∪]4;+∞[.
on lit les +

→ En b), le facteur 2−x est positif avant 2 : le produit commence par +.

Exercice 30 — Factoriser avant de résoudre

Résoudre dans R :

  1. a)
    x2−36<0
  2. b)
    x2−8x⩽0
  3. c)
    (9x2−4)(x+2)>0
  4. d)
    (x+2)2−16>0
Corrigé
L'expression n'est pas un produit : on la factorise d'abord (facteur commun ou a2−b2), puis on fait le tableau de signes.
méthode 9 du cours, exemple b)

a)

x2−36
<0
on recopie
(x−6)(x+6)
<0
on factorise : a2−b2, avec a=x et b=6

S=]−6;6[.
on lit les − ; bornes exclues

b)

x2−8x
⩽0
on recopie
x(x−8)
⩽0
on factorise par x

S=[0;8].
on lit les − et les 0

c)

(9x2−4)(x+2)
>0
on recopie
(3x−2)(3x+2)(x+2)
>0
9x2−4=(3x)2−22
3x−2=0 pour x=32​ ;   3x+2=0 pour x=−32​ ;   x+2=0 pour x=−2.
valeurs rangées : −2 ; −32​ ; 32​

S=]−2;−32​[∪]32​;+∞[.
on lit les +

d)

(x+2)2−16
>0
a2−b2, avec a=x+2 et b=4
[(x+2)−4][(x+2)+4]
>0
(x−2)(x+6)
>0
on réduit chaque crochet

S=]−∞;−6[∪]2;+∞[.
on lit les +

→ Erreur fréquente en a) : x2<36, donc x<6. On oublie alors que −7, par exemple, n'est pas solution (49>36) : le tableau de signes évite cette erreur.
