Chapitre 2 — Fonctions · coursVIII Tracer une droite d'équation ax+by+c=0

← Partie précédenteVII — Équation cartésienne d'une droitePartie suivante →IX — Passer d'une forme à l'autre

Pour tracer une droite d'équation cartésienne, on cherche deux de ses points : on choisit une valeur de x (souvent x=0), on calcule y, puis on recommence. Si b=0, la droite est verticale (x= nombre) ; si a=0, elle est horizontale (y= nombre).

Méthode 9 — Tracer une droite d'équation cartésienne

Exemples corrigés

Tracer dans un même repère les droites d1​ : x+2y−4=0, d2​ : 3x−y−2=0 et d3​ : 2x+6=0.

Correction

Résolution

d1​ : pour x=0 on a 2y−4=0, donc y=2 ; pour y=0, x=4. Points (0;2) et (4;0).
on remplace x (ou y) par 0 : les points sur les axes
d2​ : pour x=0, y=−2 ; pour x=2, 6−y−2=0, donc y=4. Points (0;−2) et (2;4).
pour y=0, x=32​ tombe mal : on choisit une autre valeur de x
d3​ : 2x+6=0 donne x=−3.
pas de y : droite verticale

À vous de jouer

Tracer dans un même repère les droites d'équations x−y+1=0 ; 2x+y−4=0 et y−3=0.

Correction

points (0;1) et (−1;0) ; points (0;4) et (2;0) ; droite horizontale y=3.

Résolution

x−y+1=0 : pour x=0, y=1 ; pour y=0, x=−1. Points (0;1) et (−1;0).
les points sur les axes
2x+y−4=0 : pour x=0, y=4 ; pour y=0, x=2. Points (0;4) et (2;0).
y−3=0 donne y=3.
pas de x : droite horizontale
