Définition 2 — Ensemble de définition

L'ensemble de définition de f, noté Df​, est l'ensemble des nombres x pour lesquels on peut calculer f(x).

Propriété 1 — Deux calculs impossibles

  • On ne divise pas par 0 : un dénominateur ne doit pas être nul.
  • La racine carrée d'un nombre négatif n'existe pas : sous une racine, il faut un nombre positif ou nul.

Sans fraction ni racine, on peut toujours calculer f(x) : Df​=R.

Exercice 5 — Valeurs interdites

On considère les fonctions

f(x)=x1​g(x)=x−5x+2​h(x)=x​

et les nombres −2 ; 5 ; 0 ; 9. Pour chaque fonction, un de ces quatre nombres n'a pas d'image : lequel ? Justifier.

Corrigé
Pour chaque fonction, on cherche le calcul impossible : une division par 0, ou la racine carrée d'un nombre négatif.
propriété 1 du cours

f

f(0)=01​ : on ne divise pas par 0. Le nombre sans image est 0.
les autres en ont une : f(−2)=−21​, f(5)=51​, f(9)=91​

g

Le dénominateur x−5 vaut 0 pour x=5 : g(5)=07​ n'existe pas. Le nombre sans image est 5.
g(−2)=−70​=0 existe : un numérateur nul ne gêne pas

h

h(−2)=−2​ : un nombre négatif n'a pas de racine carrée. Le nombre sans image est −2.
0​=0 ; 5​ et 9​=3 existent

→ Piège pour g : −2 annule le numérateur, pas le dénominateur. Seul un dénominateur nul rend le calcul impossible.
