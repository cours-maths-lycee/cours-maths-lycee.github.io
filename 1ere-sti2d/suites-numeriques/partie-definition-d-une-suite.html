Pour commencer

Écrivons les nombres pairs à partir de 2 : 2 ; 4 ; 6 ; 8 ; 10 ; … On leur donne un numéro, en commençant à 0 :

u0​=2u1​=4u2​=6u3​=8u4​=10…

Cette liste numérotée s'appelle une suite.

Définition 1 — Suite numérique

Une suite (un​) associe un nombre un​ à chaque entier n=0, 1, 2, 3…

  • Les nombres u0​, u1​, u2​… sont les termes de la suite.
  • L'entier n est le rang du terme un​ (on lit « u indice n »).

Rang et position

Le premier terme est u0​, le deuxième u1​… : le 12e terme est u11​. Le rang vaut toujours la position moins 1.

Méthode 1 — Lire les termes d'une suite donnée par une liste

Exemples corrigés

Chaque liste donne les premiers termes d'une suite (un​), numérotée à partir de u0​. Trouver comment on passe d'un terme au suivant, puis répondre.

  1. a)
    6 ; 11 ; 16 ; 21 ; …   Donner u0​, u4​ et u7​.
  2. b)
    3 ; 6 ; 12 ; 24 ; …   Donner les deux termes suivants, puis u5​.
  3. c)
    2 ; 2 ; 4 ; 6 ; 10 ; …   Donner u3​ et u6​.
Correction

a)

On ajoute 5 : 6 ; 11 ; 16 ; 21 ; 26 ; 31 ; 36 ; 41.
on prolonge la liste jusqu'au rang demandé
u0​=6 ; u4​=26 ; u7​=41.
u7​ est le 8e nombre de la liste

b)

On multiplie par 2 : les deux termes suivants sont 48 et 96.
u5​=96.
u0​=3, donc 96 est u5​

c)

Chaque terme est la somme des deux précédents : 2 ; 2 ; 4 ; 6 ; 10 ; 16 ; 26.
4=2+2, 6=2+4, 10=4+6…
u3​=6 ; u6​=26.
on compte à partir de u0​

À vous de jouer

Pour chaque suite, donner les deux termes suivants, puis u2​ et u7​ :

4 ; 10 ; 16 ; 22 ; …1 ; 4 ; 16 ; 64 ; …1 ; 4 ; 9 ; 16 ; 25 ; …
Correction

28 et 34, u2​=16, u7​=46 ; 256 et 1024, u2​=16, u7​=16384 ; 36 et 49 (les carrés), u2​=9, u7​=64.

4 ; 10 ; 16 ; 22 ; …

On ajoute 6 : 4 ; 10 ; 16 ; 22 ; 28 ; 34 ; 40 ; 46.
on prolonge la liste jusqu'au rang demandé
Les deux termes suivants sont 28 et 34 ; u2​=16 et u7​=46.
u7​ est le 8e nombre de la liste

1 ; 4 ; 16 ; 64 ; …

On multiplie par 4 : 1 ; 4 ; 16 ; 64 ; 256 ; 1024 ; 4096 ; 16384.
Les deux termes suivants sont 256 et 1024 ; u2​=16 et u7​=16384.

1 ; 4 ; 9 ; 16 ; 25 ; …

Ce sont les carrés : 12 ; 22 ; 32… Les deux termes suivants sont 36 et 49.
les écarts 3, 5, 7, 9 augmentent de 2
u2​=9 et u7​=82=64.
on compte à partir de u0​=1

À faire : exercices 1 à 4

Exercice 1 — Suites logiques

Pour chaque liste, dire comment on passe d'un nombre au suivant, puis écrire les trois nombres suivants.

  1. a)
    5 ; 10 ; 15 ; 20 ; 25 ; …
  2. b)
    2 ; 9 ; 16 ; 23 ; 30 ; …
  3. c)
    30 ; 26 ; 22 ; 18 ; …
  4. d)
    3 ; 9 ; 27 ; 81 ; …
  5. e)
    1 ; 8 ; 27 ; 64 ; 125 ; …
  6. f)
    1 ; 3 ; 4 ; 7 ; 11 ; 18 ; …
Corrigé
Pour chaque liste, on calcule l'écart entre deux nombres qui se suivent ; s'il change, on essaie de multiplier.
on vérifie la règle sur toute la liste

a)

10−5=5 ; 15−10=5 ; 20−15=5 ; 25−20=5 : on ajoute 5.
écart toujours le même
25+5=30, puis 35, puis 40 : 30 ; 35 ; 40.

b)

9−2=7 ; 16−9=7 ; 23−16=7 ; 30−23=7 : on ajoute 7.
30+7=37, puis 44, puis 51 : 37 ; 44 ; 51.

c)

26−30=−4 ; 22−26=−4 ; 18−22=−4 : on enlève 4.
l'écart est négatif : la liste descend
18−4=14, puis 10, puis 6 : 14 ; 10 ; 6.

d)

9−3=6 mais 27−9=18 : on n'ajoute pas toujours le même nombre.
on essaie de multiplier
39​=3 ; 927​=3 ; 2781​=3 : on multiplie par 3.
81×3=243, puis 729, puis 2187 : 243 ; 729 ; 2187.
243×3=729 ; 729×3=2187

e)

Les écarts 7 ; 19 ; 37 ; 61 changent, et 18​=8 mais 827​ n'est pas entier.
ni une addition, ni une multiplication
Ce sont les cubes : 13=1 ; 23=8 ; 33=27 ; 43=64 ; 53=125.
33=3×3×3
63=216 ; 73=343 ; 83=512 : 216 ; 343 ; 512.
6×6×6=36×6

f)

1+3=4 ; 3+4=7 ; 4+7=11 ; 7+11=18 : chaque nombre est la somme des deux précédents.
on regarde les deux nombres d'avant
11+18=29 ; 18+29=47 ; 29+47=76 : 29 ; 47 ; 76.

Exercice 2 — Rang et position

La suite (un​) commence par 7 ; 13 ; 19 ; 25 ; …, avec u0​=7.

  1. 1)
    Donner u1​ et u3​.
  2. 2)
    Quel est le rang du 5e terme ? Calculer ce terme.
  3. 3)
    Calculer u8​. À quelle position de la liste se trouve-t-il ?
Corrigé
D'un terme au suivant, on ajoute 6 : 13−7=6 ; 19−13=6 ; 25−19=6. On prolonge la liste en numérotant à partir de u0​ :
le premier terme est u0​
Position1er2e3e4e5e6e7e8e9e
Rang n012345678
un​71319253137434955

1)

u1​=13 et u3​=25.
u1​ est le 2e nombre de la liste

2)

Le 5e terme est de rang 4 : c'est u4​=25+6=31.
le rang vaut la position moins 1

3)

u8​=55 : c'est le 9e nombre de la liste.
la position vaut le rang plus 1

→ Erreur fréquente : prendre u4​ pour le 4e terme. Comme on commence à u0​, le 4e terme est u3​.

Exercice 3 — Lire un tableau

Voici les premiers termes d'une suite (un​).

n012345
un​151173−1−5
  1. 1)
    Donner u3​, puis le 3e terme de la suite.
  2. 2)
    Pour quel rang n a-t-on un​=−1 ?
  3. 3)
    Comment passe-t-on d'un terme au suivant ? En déduire u6​.
Corrigé

1)

Dans la colonne n=3, on lit u3​=3.
le rang est dans la première ligne
Le 3e terme est u2​ : il vaut 7.
1er terme : u0​ ; 2e : u1​ ; 3e : u2​

2)

On cherche −1 dans la deuxième ligne : il est dans la colonne n=4. Donc un​=−1 pour n=4.
on lit le tableau dans l'autre sens

3)

11−15=−4 ; 7−11=−4 ; 3−7=−4 ; −1−3=−4 ; −5−(−1)=−4 : on enlève 4 à chaque fois.
−5−(−1)=−5+1
u6​
=u5​−4
on enlève 4 au terme précédent
u6​
=−5−4=−9

Exercice 4 — Les tribunes d'un stade

Dans une tribune, la première rangée compte 30 sièges, et chaque rangée en compte 4 de plus que la précédente. On note u0​=30 le nombre de sièges de la première rangée, u1​ celui de la deuxième, etc.

  1. 1)
    Calculer u1​, u2​, u3​ et u4​.
  2. 2)
    Combien de sièges compte la 10e rangée ?
  3. 3)
    Quelle rangée compte 70 sièges ?
Corrigé

1)

u1​
=30+4=34
la 2e rangée : 4 sièges de plus
u2​
=34+4=38
toujours à partir de la rangée d'avant
u3​
=38+4=42
u4​
=42+4=46

2)

La 10e rangée correspond à u9​.
la 1re rangée est u0​ : le rang vaut la position moins 1
u5​
=46+4=50
on continue la liste
u6​
=50+4=54
u7​
=54+4=58
u8​
=58+4=62
u9​
=62+4=66
La 10e rangée compte 66 sièges.
contrôle : de u0​ à u9​, on a ajouté 9 fois 4 ; 30+36=66

3)

De 30 à 70, il faut 40 sièges de plus, soit 10 fois 4 : c'est u10​.
40÷4=10
Contrôle : u10​=66+4=70.
on ajoute 4 à u9​
u10​ est la 11e rangée.
la position vaut le rang plus 1

→ Piège du décalage : u10​ n'est pas la 10e rangée, mais la 11e.
