Exercice 17 — Écrire la fonction

La suite (vn​) est définie par v0​=4 et vn+1​=3vn​−5.

  1. 1.
    Écrire une fonction terme_v(n) qui renvoie vn​.
  2. 2.
    Que renvoie terme_v(10) ?
Corrigé

1.

def terme_v(n):
    v = 4
    for i in range(n):
        v = 3*v - 5
    return v

v = 4 donne v0​ ; la boucle tourne n fois, de v0​ à vn​ ; dans v = 3*v - 5, le v de droite est le terme précédent, celui de gauche le terme suivant : c'est la relation vn+1​=3vn​−5

→ Erreurs fréquentes : placer v = 4 dans la boucle (on repartirait de v0​ à chaque tour) ; décaler return v dans la boucle (la fonction s'arrêterait au premier tour).

2.

terme_v(10) renvoie 88576 : v10​=88576.
dans la console : terme_v(10)
Contrôle : terme_v(1) renvoie 7, et à la main v1​=3×4−5=7.
un petit rang se vérifie à la main

Exercice 19 — Une relation qui dépend de n

La suite (wn​) est définie par w0​=0 et wn+1​=wn​+2n+3.

def terme_w(n):
    w = 0
    for i in range(n):
        w = ..........
    return w
  1. 1.
    Calculer w1​, w2​ et w3​.
  2. 2.
    Compléter la fonction (dans la boucle, i joue le rôle de n).
  3. 3.
    Que renvoie terme_w(10) ?
Corrigé

1.

w1​
=w0​+2×0+3
la relation avec n=0
w1​
=0+0+3=3
w2​
=w1​+2×1+3
n=1
w2​
=3+2+3=8
w3​
=w2​+2×2+3
n=2
w3​
=8+4+3=15

2.

def terme_w(n):
    w = 0
    for i in range(n):
        w = w + 2*i + 3
    return w

i prend les valeurs 0 ; 1 ; … ; n−1 ; au tour où i vaut k, w contient wk​ et devient wk+1​=wk​+2k+3 : i joue le rôle du n de la relation

→ Erreur fréquente : écrire 2*n dans la boucle. Le paramètre n est le nombre de tours, il ne change pas ; c'est i qui avance d'un rang à chaque tour.
