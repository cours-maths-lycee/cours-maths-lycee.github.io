Définition 7 — Seuil

Chercher un seuil, c'est chercher le premier rang n à partir duquel un​ dépasse une valeur donnée (ou passe en dessous). On le trouve avec le tableau de la calculatrice, ou avec un programme qui calcule les termes un par un tant que la valeur n'est pas atteinte.

Méthode 14 — Déterminer un seuil dans un problème

Exemples corrigés

Un club d'escalade compte 2000 adhérents en septembre 2026. Chaque année, 10% des adhérents ne se réinscrivent pas et 500 nouveaux adhérents arrivent. On note un​ le nombre d'adhérents en septembre de l'année 2026+n.

  1. a)
    Calculer u1​ et u2​.
  2. b)
    Justifier que, pour tout entier naturel n, un+1​=0,9un​+500.
  3. c)
    Compléter la fonction ci-dessous pour qu'elle renvoie le nombre d'années au bout duquel le club dépasse 4000 adhérents.
  4. d)
    À l'aide de la calculatrice, déterminer l'année où le club dépasse 4000 adhérents.
def seuil():
    u = 2000
    n = 0
    while .......... :
        u = ..........
        n = n + 1
    return n
Correction

a)

u1​
=2000−0,1×2000+500
on retire 10%, on ajoute les nouveaux
u1​
=2000−200+500=2300
u2​
=2300−230+500=2570
10% de 2300 : 230

b)

Retirer 10%, c'est multiplier par 0,9 ; on ajoute ensuite les 500 nouveaux : un+1​=0,9un​+500.
comme à la méthode 6

c)

def seuil():
    u = 2000
    n = 0
    while u <= 4000 :
        u = 0.9*u + 500
        n = n + 1
    return n

tant que le seuil n'est pas dépassé (u⩽4000, le contraire de « dépasser »), on passe au terme suivant (relation de récurrence) et au rang suivant ; la boucle s'arrête au premier terme qui dépasse 4000, et n est son rang

d)

Tableau de la calculatrice : u10​≃3954 et u11​≃4059.
le premier terme au-dessus de 4000 est u11​
seuil() renvoie 11 : le club dépasse 4000 adhérents en septembre 2037.
2026+11=2037

coefficient multiplicateur

Exercice 41 — Abonnés d'une newsletter

Une newsletter compte 3000 abonnés en janvier. Chaque mois, 15% des abonnés se désinscrivent et 800 nouveaux s'inscrivent. On note un​ le nombre d'abonnés au bout de n mois.

  1. 1.
    Calculer u1​ et u2​.
  2. 2.
    Justifier que un+1​=0,85un​+800.
  3. 3.
    Écrire une fonction seuil() qui renvoie le premier mois où l'on dépasse 5000 abonnés.
  4. 4.
    À l'aide de la calculatrice, donner ce mois.
Corrigé
  1. 1.
    u1​=0,85×3000+800=3350 ; u2​=0,85×3350+800=3647,5.
  2. 2.
    15% partent : il reste 0,85un​ ; on ajoute 800.
  3. 3.
    def seuil():
    u = 3000
    n = 0
    while u <= 5000 :
        u = 0.85*u + 800
        n = n + 1
    return n
  4. 4.
    u11​≃4942,9 et u12​≃5001,4 : au bout de 12 mois.

Exercice 43 — Élimination d'un médicament

Un patient reçoit 40 mg d'un médicament. Chaque heure, son corps en élimine 20%. On note mn​ la quantité, en mg, présente au bout de n heures.

  1. 1.
    Calculer m1​ et m2​, puis exprimer mn+1​ en fonction de mn​.
  2. 2.
    Écrire une fonction seuil() qui renvoie le nombre d'heures au bout duquel il reste moins de 5 mg.
  3. 3.
    Donner ce nombre d'heures.
Corrigé
  1. 1.
    m1​=32 ; m2​=25,6 ; mn+1​=0,8mn​.
  2. 2.
    def seuil():
    m = 40
    n = 0
    while m >= 5 :
        m = 0.8*m
        n = n + 1
    return n
  3. 3.
    m9​≃5,37 et m10​≃4,29 : 10 heures.

Exercice 44 — Qui dépasse l'autre ?

Un site compte 500 abonnés payants et en gagne 40 par mois ; un autre en compte 200 et gagne 10% d'abonnés par mois. On note an​=500+40n et bn​ leurs abonnés au bout de n mois (b0​=200 et bn+1​=1,1bn​).

def depasse():
    b = 200
    n = 0
    while b <= 500 + 40*n :
        b = 1.1*b
        n = n + 1
    return n
  1. 1.
    Expliquer ce que renvoie cette fonction.
  2. 2.
    À l'aide de la calculatrice, donner le résultat et l'interpréter.
Corrigé
  1. 1.
    Tant que bn​⩽an​=500+40n, on passe au mois suivant : la fonction renvoie le premier mois où le second site a plus d'abonnés que le premier.
  2. 2.
    b19​≃1223<a19​=1260 et b20​≃1345>a20​=1300 : elle renvoie 20 ; au bout de 20 mois, le site à +10% dépasse l'autre.

Exercice 45 — Automatismes (QCM)

Pour chaque question, une seule réponse est exacte.

  1. 1.

    un​=n2−1 ; alors un+1​ vaut :

    a) n2   b) n2+2n   c) n2+1   d) n2+2n+2

  2. 2.

    u0​=2 et un+1​=3un​−1 ; alors u2​ vaut :

    a) 5   b) 14   c) 17   d) 8

  3. 3.

    Baisser de 15% revient à multiplier par :

    a) 0,15   b) 1,15   c) 0,85   d) −15

  4. 4.

    Si un+1​−un​=−n2−1 pour tout n, la suite (un​) est :

    a) croissante   b) décroissante   c) constante   d) on ne peut pas savoir

  5. 5.

    La limite de un​=3+n1​ semble être :

    a) 0   b) 3   c) 4   d) +∞

Corrigé

1. b) : (n+1)2−1=n2+2n ;  2. b) : u1​=5 puis u2​=14 ;  3. c) ;  4. b) : la différence est négative ;  5. b).

Exercice 46 — Une plateforme de covoiturage

Une plateforme locale de covoiturage compte 600 conducteurs inscrits en janvier 2026. Chaque mois, 10% des conducteurs se désinscrivent et 40 nouveaux s'inscrivent. On note un​ le nombre de conducteurs au bout de n mois ; ainsi u0​=600.

  1. 1.
    Calculer u1​ et u2​, puis justifier que un+1​=0,9un​+40.
  2. 2.
    On admet que, pour tout entier n, un​=400+200×0,9n. Vérifier cette formule pour n=0 et n=1.
  3. 3.
    Montrer que un+1​−un​=−20×0,9n. En déduire le sens de variation de (un​).
  4. 4.
    Conjecturer la limite de (un​). Interpréter.
  5. 5.

    Compléter la fonction pour qu'elle renvoie le premier mois où il y a moins de 450 conducteurs, puis donner ce mois.

    def seuil():
    u = 600
    n = 0
    while .......... :
        u = ..........
        n = n + 1
    return n
Corrigé
  1. 1.
    u1​=0,9×600+40=580 ; u2​=0,9×580+40=562. Il reste 90% des conducteurs, puis 40 s'ajoutent : un+1​=0,9un​+40.
  2. 2.
    n=0 : 400+200=600=u0​ ; n=1 : 400+180=580=u1​.
  3. 3.
    un+1​−un​
    =200×0,9n+1−200×0,9n
    les 400 s'éliminent
    un+1​−un​
    =200×0,9n(0,9−1)
    facteur commun
    un+1​−un​
    =−20×0,9n

    0,9n>0, donc la différence est négative : (un​) est strictement deˊcroissante.

  4. 4.
    0,9n se rapproche de 0 : n→+∞lim​un​=400. Le nombre de conducteurs se stabiliserait vers 400.
  5. 5.
    while u >= 450 : et u = 0.9*u + 40. u13​≃450,8 et u14​≃445,8 : la fonction renvoie 14, soit mars 2027.

Exercice 47 — Coût moyen de fabrication

Un atelier fabrique n lampes par jour (n⩾1). Le coût moyen de fabrication d'une lampe, en euros, est cn​=n+n400​.

  1. 1.
    Calculer c1​, c10​ et c20​.
  2. 2.
    On pose f(x)=x+x400​ sur [1;+∞[. Calculer f′(x), puis dresser le tableau de variations de f.
  3. 3.
    En déduire le sens de variation de (cn​) et le nombre de lampes qui rend le coût moyen le plus faible.
  4. 4.
    Pour n⩾20, à partir de quel nombre de lampes le coût moyen dépasse-t-il 50 € ? On résoudra n2−50n+400>0.
Corrigé
  1. 1.
    c1​=401 ; c10​=10+40=50 ; c20​=20+20=40.
  2. 2.
    f′(x)
    =1−x2400​
    (x1​)′=−x21​
    f′(x)
    =x2x2−400​=x2(x−20)(x+20)​

  3. 3.
    (cn​) décroît jusqu'au rang 20, puis croît : le coût moyen est le plus faible pour 20 lampes (40 €).
  4. 4.
    Pour n>0, cn​>50 revient à n2+400>50n, soit n2−50n+400>0. Δ=900 ; racines 10 et 40 ; le trinôme est positif à l'extérieur des racines. Pour n⩾20 : n⩾41.
