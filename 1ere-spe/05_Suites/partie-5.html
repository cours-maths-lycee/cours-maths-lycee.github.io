Méthode 8 — Programmer le calcul d'un terme en Python

Exemples corrigés

On reprend la suite (vn​) définie par v0​=1 et vn+1​=2vn​+3.

  1. a)
    Écrire une fonction terme_v(n) qui renvoie vn​.
  2. b)
    Que renvoie terme_v(10) ?
Correction

a)

def terme_v(n):
    v = 1
    for i in range(n):
        v = 2*v + 3
    return v

v = 1 donne v0​ ; la boucle tourne n fois, de v0​ à vn​ ; dans v = 2*v + 3, le nouveau v est le terme suivant, l'ancien est le terme précédent

b)

terme_v(10) renvoie 4093 : v10​=4093.
comme avec la calculatrice

Exercice 17 — Écrire la fonction

La suite (vn​) est définie par v0​=4 et vn+1​=3vn​−5.

  1. 1.
    Écrire une fonction terme_v(n) qui renvoie vn​.
  2. 2.
    Que renvoie terme_v(10) ?
Corrigé
def terme_v(n):
    v = 4
    for i in range(n):
        v = 3*v - 5
    return v

terme_v(10) renvoie 88576.

Exercice 18 — Lire un programme

On considère la fonction ci-dessous.

def mystere(n):
    u = 5
    for i in range(n):
        u = u/2 + 3
    return u
  1. 1.
    Quelle suite cette fonction calcule-t-elle ? Donner son premier terme et sa relation de récurrence.
  2. 2.
    Calculer à la main ce que renvoient mystere(1), mystere(2) et mystere(3).
Corrigé
  1. 1.
    La suite définie par u0​=5 et un+1​=2un​​+3 : la fonction renvoie un​.
  2. 2.
    mystere(1)=25​+3=5,5 ; mystere(2)=25,5​+3=5,75 ; mystere(3)=25,75​+3=5,875.

Exercice 19 — Une relation qui dépend de n

La suite (wn​) est définie par w0​=0 et wn+1​=wn​+2n+3.

def terme_w(n):
    w = 0
    for i in range(n):
        w = ..........
    return w
  1. 1.
    Calculer w1​, w2​ et w3​.
  2. 2.
    Compléter la fonction (dans la boucle, i joue le rôle de n).
  3. 3.
    Que renvoie terme_w(10) ?
Corrigé
  1. 1.
    w1​=0+0+3=3 ; w2​=3+2+3=8 ; w3​=8+4+3=15.
  2. 2.
    Ligne à compléter : w = w + 2*i + 3.
  3. 3.
    terme_w(10) renvoie 120.

→ À la première boucle, i vaut 0 : on calcule bien w1​ à partir de w0​.

Exercice 20 — La suite de Fibonacci

La suite (fn​) est définie par f0​=1, f1​=1 et, pour tout n, fn+2​=fn+1​+fn​ : chaque terme est la somme des deux précédents.

def fibo(n):
    a = 1
    b = 1
    for i in range(n-1):
        a, b = b, ..........
    return b
  1. 1.
    Calculer f2​ à f6​.
  2. 2.
    Compléter la fonction (a et b contiennent deux termes qui se suivent) pour qu'elle renvoie fn​, pour n⩾1.
  3. 3.
    Que renvoie fibo(20) ?
Corrigé
  1. 1.
    f2​=2 ; f3​=3 ; f4​=5 ; f5​=8 ; f6​=13.
  2. 2.
    Ligne à compléter : a, b = b, a + b (le nouveau terme est la somme des deux précédents).
  3. 3.
    fibo(20) renvoie 10946.
