Définition 2 — Racines et discriminant

Les racines d'un trinôme sont les solutions de l'équation ax2+bx+c=0.

Le discriminant du trinôme est le nombre Δ=b2−4ac.

Théorème 2 — Nombre de racines

  • Si Δ>0 : deux racines x1​=2a−b+Δ​​ et x2​=2a−b−Δ​​.
  • Si Δ=0 : une seule racine (dite double) x0​=−2ab​.
  • Si Δ<0 : aucune racine réelle.

Pourquoi ?

En reprenant la démonstration de la partie I, la forme canonique s'écrit

P(x)=a[(x−α)2−4a2Δ​]

Si Δ<0, le crochet est la somme d'un carré et d'un nombre strictement positif : il ne s'annule pas. Si Δ=0, il reste a(x−α)2, nul seulement en α. Si Δ>0, le crochet est une différence de deux carrés, qui se factorise et donne deux racines.

Exercice 5 — Factoriser plutôt que calculer Δ

Résoudre chaque équation en factorisant, sans discriminant.

  1. 1)
    9x2−4=0
  2. 2)
    x2−6x=0
  3. 3)
    2x2−18=0
  4. 4)
    x2−5=0
  5. 5)
    (3x−2)(x+5)=0
  6. 6)
    x2−10x+25=0
Corrigé
  1. 1)
    9x2−4=(3x−2)(3x+2) : S={−32​;32​}
  2. 2)
    x2−6x=x(x−6) : S={0;6}
  3. 3)
    2x2−18=2(x−3)(x+3) : S={−3;3}
  4. 4)
    x2−5=(x−5​)(x+5​) : S={−5​;5​}
  5. 5)
    3x−2=0 ou x+5=0 : S={−5;32​}
  6. 6)
    x2−10x+25=(x−5)2 : S={5}

→ Facteur commun, identité remarquable, produit déjà factorisé : calculer Δ ferait perdre du temps.

Exercice 6 — Avec le discriminant

Résoudre dans R en calculant le discriminant.

  1. 1)
    x2+x−12=0
  2. 2)
    x2+3x+5=0
  3. 3)
    −x2+6x−9=0
  4. 4)
    t2−4t−21=0
  5. 5)
    2−y−3y2=0
  6. 6)
    −2x2+5x+1=0
Corrigé
  1. 1)
    Δ=1+48=49>0 : x1​=2−1−7​=−4 et x2​=2−1+7​=3. S={−4;3}
  2. 2)
    Δ=9−20=−11<0 : S=∅
  3. 3)
    Δ=36−36=0 : racine double x0​=−2×(−1)6​=3. S={3}
  4. 4)
    Δ=16+84=100 : t=24±10​. S={−3;7}
  5. 5)
    On ordonne : −3y2−y+2=0, donc a=−3, b=−1 et c=2. Δ=1+24=25 : y=−61±5​. S={−1;32​}
  6. 6)
    Δ=25+8=33>0 : x=−4−5±33​​=45∓33​​. S={45−33​​;45+33​​}

→ En 3), le trinôme vaut −(x−3)2. En 5), on range l'équation dans l'ordre ay2+by+c avant de lire a, b, c : l'erreur de signe est fréquente.

Exercice 8 — Une parabole et une droite

  1. 1)
    Dans un même repère, tracer l'allure de la parabole d'équation y=x2 et la droite d'équation y=2x+3.
  2. 2)
    Expliquer pourquoi les solutions de x2−2x−3=0 sont les abscisses des points communs aux deux courbes. Combien cette équation a-t-elle de solutions ? Les lire.
  3. 3)
    Résoudre x2−2x−3=0 par le calcul.
Corrigé
  1. 1)
    Voir la figure.
  2. 2)
    x2−2x−3=0⟺x2=2x+3 : les solutions sont les abscisses des points communs à la parabole et à la droite. Il y en a deux ; on lit −1 et 3.
  3. 3)
    Δ=4+12=16, donc x=22±4​. S={−1;3}
    On vérifie : (−1)2=1=2×(−1)+3 et 32=9=2×3+3.

Exercice 9 — Un programme Python

La fonction racines renvoie la liste des solutions de ax2+bx+c=0.

from math import sqrt

def racines(a, b, c):
    d = b*b - 4*a*c
    if d < 0:
        return []
    if d == 0:
        return [-b/(2*a)]
    r = sqrt(d)
    return [(-b - r)/(2*a), (-b + r)/(2*a)]
  1. 1)
    Que représente la variable d ? Que renvoie la fonction selon son signe ?
  2. 2)
    Saisir ce programme, puis le tester sur les six équations de l'exercice 6 : retrouve-t-on les résultats obtenus à la main ?
  3. 3)
    Que se passe-t-il avec racines(0, 3, -12) ? Pourquoi ? Quelle est pourtant la solution de 3x−12=0 ?
  4. 4)
    Comparer racines(1, 6, 9) et racines(0.2, 1.2, 1.8). Le second trinôme vaut 0,2(x+3)2 : quelle réponse attendait-on ? Pourquoi un test d'égalité est-il fragile avec des nombres à virgule ?
Corrigé
  1. 1)
    d est le discriminant Δ. Si d < 0, la fonction renvoie une liste vide (aucune solution) ; si d == 0, la seule racine −2ab​ ; sinon, les deux racines.
  2. 2)
    On retrouve l'exercice 6 : [-4.0, 3.0] ; [] ; [3.0] ; [-3.0, 7.0] ; avec (−3;−1;2) : [0.666..., -1.0] ; avec (−2;5;1) : [2.686..., -0.186...], valeurs approchées de 45+33​​ et de 45−33​​.
  3. 3)
    Ici Δ=9>0 et le programme divise par 2a=0 : erreur de division par zéro. Avec a=0, l'équation n'est pas du second degré et les formules ne s'appliquent pas. Pourtant 3x−12=0⟺x=4.
  4. 4)
    racines(1, 6, 9) renvoie [-3.0] : Δ=0 exactement. Pour 0,2(x+3)2 on attendait aussi −3, mais le programme renvoie [] : les nombres à virgule sont enregistrés en valeur approchée, d vaut environ −2,2×10−16 au lieu de 0, et le test d < 0 est vrai.

→ Le résultat exact peut dépendre de la machine ; l'essentiel est de comprendre qu'un test d'égalité sur des nombres à virgule calculés est fragile.
