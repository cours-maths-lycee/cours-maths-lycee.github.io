Propriété 4 — Quotient nul

Un quotient est nul si et seulement si son numérateur est nul, son dénominateur ne l'étant pas :

BA​=0⟺A=0 et B=0

Méthode 9 — Résoudre une équation quotient

Exemples corrigés

Résoudre dans R les équations suivantes.

  1. a)
    Un quotient nul : x+52x−8​=0.
  2. b)
    Un quotient égal à un nombre : x−2x+7​=4.
  3. c)
    Un quotient égal à un quotient : x−3x+1​=x−1x+2​.
Correction

a)

Valeur interdite : −5.
on commence par les valeurs interdites
2x−8=0 pour x=4, qui n'est pas interdit : S={4}.
un quotient est nul quand son numérateur est nul

b)

Valeur interdite : 2.
x−2x+7​=4
⟺x−2x+7​−4=0
tout dans un membre
⟺x−2x+7−4(x−2)​=0
un seul quotient (méthode 8)
⟺x−2−3x+15​=0
−3x+15=0 pour x=5, qui n'est pas interdit : S={5}.
on résout « numérateur =0 », puis on écarte les valeurs interdites

c)

Valeurs interdites : 3 et 1.
x−3x+1​=x−1x+2​
⟺x−3x+1​−x−1x+2​=0
⟺(x−3)(x−1)(x+1)(x−1)−(x+2)(x−3)​=0
(x+1)(x−1)−(x+2)(x−3)
=x2−1−(x2−x−6)
le numérateur à part
(x+1)(x−1)−(x+2)(x−3)
=x+5
x−3x+1​=x−1x+2​
⟺(x−3)(x−1)x+5​=0
x+5=0 pour x=−5, qui n'est pas interdit : S={−5}.
numérateur nul, valeur non interdite

Deux remarques

  • Une solution du numérateur peut être interdite : on l'écarte. Ainsi x−3x2−9​=0 donne x=3 ou x=−3, mais 3 est interdit : S={−3}.
  • Le produit en croix donne aussi le résultat en c), mais il ne sert plus pour les inéquations (partie VII) : on retient la méthode du quotient nul.

À vous de jouer

Résoudre dans R, en donnant d'abord les valeurs interdites :

x−43x+9​=0x+1x+9​=3x+2x+4​=x−2x−1​
Correction

x=4 : S={−3} ; x=−1 : x+1−2x+6​=0, S={3} ; x=−2 et x=2 : le numérateur vaut x−6, S={6}.

Quotient égal à 0

Valeur interdite : 4.
on commence par les valeurs interdites
3x+9=0 pour x=−3, qui n'est pas interdit : S={−3}.
un quotient est nul quand son numérateur est nul

Quotient égal à un nombre

Valeur interdite : −1.
x+1x+9​=3
⟺x+1x+9​−3=0
tout dans un membre
⟺x+1x+9−3(x+1)​=0
un seul quotient (méthode 8)
⟺x+1−2x+6​=0
−2x+6=0 pour x=3, qui n'est pas interdit : S={3}.
numérateur nul, valeur non interdite

Quotient égal à un quotient

Valeurs interdites : −2 et 2.
x+2x+4​=x−2x−1​
⟺x+2x+4​−x−2x−1​=0
⟺(x+2)(x−2)(x+4)(x−2)−(x−1)(x+2)​=0
(x+4)(x−2)−(x−1)(x+2)
=x2+2x−8−(x2+x−2)
le numérateur à part
(x+4)(x−2)−(x−1)(x+2)
=x−6
x+2x+4​=x−2x−1​
⟺(x+2)(x−2)x−6​=0
x−6=0 pour x=6, qui n'est pas interdit : S={6}.
numérateur nul, valeur non interdite

Exercice 17 — Quotient nul

Donner les valeurs interdites, puis résoudre dans R :

  1. a)
    x+24x−12​=0
  2. b)
    5x23x+6​=0
  3. c)
    x+1(x−3)(2x+5)​=0
  4. d)
    x2+37−2x​=0
Corrigé
Propriété 4 : un quotient est nul si et seulement si son numérateur est nul, son dénominateur ne l'étant pas. On cherche donc les valeurs interdites, puis on résout «  numérateur =0 » et on écarte les valeurs interdites.
méthode 9, exemple a)

a)

Valeur interdite : −2.
x+2=0 pour x=−2
4x−12=0
⟺4x=12
numérateur nul
⟺x=3
3 n'est pas interdit : S={3}.

b)

5x2=0 pour x=0 : valeur interdite 0.
3x+6=0
⟺3x=−6
⟺x=−2
−2 n'est pas interdit : S={−2}.

c)

Valeur interdite : −1.
(x−3)(2x+5)=0
⟺x−3=0 ou 2x+5=0
le numérateur est un produit nul
⟺x=3 ou x=−25​
Aucune des deux valeurs n'est interdite : S={−25​;3}.

d)

x2⩾0, donc x2+3⩾3 : le dénominateur ne s'annule jamais. Aucune valeur interdite.
un carré n'est jamais négatif
7−2x=0
⟺−2x=−7
⟺x=27​
on divise par −2
S={27​}.

→ Erreur fréquente : résoudre aussi «  dénominateur =0 » et ajouter ces valeurs aux solutions. Le dénominateur ne sert qu'à écarter des valeurs, jamais à en fournir.

Exercice 18 — Se ramener à un quotient nul

Donner les valeurs interdites, se ramener à un quotient égal à 0, puis résoudre :

  1. a)
    x+43x+2​=2
  2. b)
    x+2−3x​=1
  3. c)
    x1​+31​=1
  4. d)
    x−65​+1=0
  5. e)
    3−x+28−x​=0
  6. f)
    x−4x2−16​=0
Corrigé
Quand le second membre n'est pas 0, on fait tout passer dans un membre, on écrit un seul quotient (méthode 8), puis on applique la propriété 4.
méthode 9, exemple b)

a)

Valeur interdite : −4.
x+43x+2​=2
⟺x+43x+2​−2=0
tout dans un membre
⟺x+43x+2−2(x+4)​=0
un seul quotient : 2=x+42(x+4)​
⟺x+43x+2−2x−8​=0
⟺x+4x−6​=0
x−6=0 pour x=6, qui n'est pas interdit : S={6}.
numérateur nul, valeur non interdite

b)

Valeur interdite : −2.
x+2−3x​=1
⟺x+2−3x​−1=0
tout dans un membre
⟺x+2−3x−(x+2)​=0
1=x+2x+2​
⟺x+2−4x−2​=0
−4x−2=0 pour x=−21​, qui n'est pas interdit : S={−21​}.
−4x=2, puis on divise par −4

c)

Valeur interdite : 0.
dénominateur commun : 3x
x1​+31​=1
⟺x1​+31​−1=0
tout dans un membre
⟺3x3​+3xx​−3x3x​=0
chaque terme sur 3x
⟺3x3−2x​=0
3−2x=0 pour x=23​, qui n'est pas interdit : S={23​}.
vérification : 32​+31​=1

d)

Valeur interdite : 6.
x−65​+1=0
⟺x−65+(x−6)​=0
déjà un membre nul ; 1=x−6x−6​
⟺x−6x−1​=0
x−1=0 pour x=1, qui n'est pas interdit : S={1}.

e)

Valeur interdite : −2.
3−x+28−x​=0
⟺x+23(x+2)−(8−x)​=0
on garde la parenthèse derrière le «  − »
⟺x+23x+6−8+x​=0
⟺x+24x−2​=0
4x−2=0 pour x=21​, qui n'est pas interdit : S={21​}.

f)

Valeur interdite : 4.
le quotient est déjà égal à 0
x2−16=0
⟺x2=16
numérateur nul
⟺x=−4 ou x=4
propriété 3
Mais 4 est interdit : on l'écarte. S={−4}.
le quotient n'existe pas pour x=4

→ En f), une solution du numérateur est une valeur interdite : on l'écarte. C'est pour cela qu'on écrit toujours les valeurs interdites en premier.

Exercice 19 — Égalité de deux quotients

Donner les valeurs interdites, puis résoudre dans R :

  1. a)
    x+25​=x3​
  2. b)
    x2x+1​=x+12x+5​
  3. c)
    x+13x−2​=x−23x+1​
  4. d)
    x−2x+4​−3=x−28−x​
  5. e)
    x−1x+5​=x−13​
  6. f)
    1−x−1x+1​=3−x4​
Corrigé
Méthode du cours : on fait tout passer dans un membre, on réduit au même dénominateur, puis quotient nul. (Le produit en croix donnerait aussi le résultat ici, mais il ne sert plus pour les inéquations de la partie suivante.)
méthode 9, exemple c)

a)

Valeurs interdites : −2 et 0.
dénominateur commun x(x+2)
x+25​=x3​
⟺x+25​−x3​=0
tout dans un membre
⟺x(x+2)5x−3(x+2)​=0
chaque fraction reçoit ce qui lui manque
⟺x(x+2)2x−6​=0
5x−3x−6=2x−6
2x−6=0 pour x=3, qui n'est pas interdit : S={3}.
vérification : 55​=1 et 33​=1

b)

Valeurs interdites : 0 et −1.
x2x+1​=x+12x+5​
⟺x2x+1​−x+12x+5​=0
⟺x(x+1)(2x+1)(x+1)−x(2x+5)​=0
On calcule le numérateur à part.
calcul intermédiaire
(2x+1)(x+1)−x(2x+5)
=2x2+2x+x+1−2x2−5x
−x(2x+5)=−2x2−5x
(2x+1)(x+1)−x(2x+5)
=−2x+1
les x2 s'éliminent
L'équation équivaut à x(x+1)−2x+1​=0 ; −2x+1=0 pour x=21​, qui n'est pas interdit : S={21​}.

c)

Valeurs interdites : −1 et 2.
x+13x−2​=x−23x+1​
⟺x+13x−2​−x−23x+1​=0
⟺(x+1)(x−2)(3x−2)(x−2)−(3x+1)(x+1)​=0
On calcule le numérateur à part.
(3x−2)(x−2)−(3x+1)(x+1)
=(3x2−8x+4)−(3x2+4x+1)
produits entre parenthèses
(3x−2)(x−2)−(3x+1)(x+1)
=3x2−8x+4−3x2−4x−1
(3x−2)(x−2)−(3x+1)(x+1)
=−12x+3
−12x+3=0 pour x=123​, soit x=41​, qui n'est pas interdit : S={41​}.
on simplifie la fraction par 3

d)

Valeur interdite : 2.
un seul dénominateur, x−2
x−2x+4​−3=x−28−x​
⟺x−2x+4​−3−x−28−x​=0
tout dans un membre
⟺x−2x+4−3(x−2)−(8−x)​=0
3=x−23(x−2)​
⟺x−2x+4−3x+6−8+x​=0
⟺x−2−x+2​=0
−x+2=0 pour x=2, qui est interdit : l'équation n'a pas de solution, S=∅.
la seule valeur trouvée est écartée

e)

Valeur interdite : 1.
les deux dénominateurs sont égaux
x−1x+5​=x−13​
⟺x−1x+5−3​=0
même dénominateur : on soustrait les numérateurs
⟺x−1x+2​=0
x+2=0 pour x=−2, qui n'est pas interdit : S={−2}.

f)

Valeurs interdites : 1 et 3. Calcul long : on réduit d'abord le membre de gauche.
x−1=0 pour x=1 ; 3−x=0 pour x=3
1−x−1x+1​
=x−1x−1​−x−1x+1​
1=x−1x−1​
1−x−1x+1​
=x−1x−1−x−1​
le «  − » change les signes de x+1
1−x−1x+1​
=x−1−2​
Puis on résout l'équation obtenue.
dénominateur commun (x−1)(3−x)
x−1−2​=3−x4​
⟺x−1−2​−3−x4​=0
⟺(x−1)(3−x)−2(3−x)−4(x−1)​=0
⟺(x−1)(3−x)−6+2x−4x+4​=0
⟺(x−1)(3−x)−2x−2​=0
−2x−2=0 pour x=−1, qui n'est pas interdit : S={−1}.
vérification : 1−−20​=1 et 44​=1

→ En d), la seule valeur trouvée est interdite : pas de solution. En e), les dénominateurs sont égaux : on compare directement les numérateurs, en gardant la valeur interdite.
